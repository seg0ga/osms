## Заключение
В ходе расчетно-графической работы вмбыла смоделирована полная цепочка передачи и приема цифрового сообщения по зашумленному каналу связи. В качестве исходных данных использовалась строка «Demin Sergei», переведенная в последовательность из 96 бит по таблице ASCII. Для контроля целостности к данным была добавлена 6-битная контрольная сумма CRC, а для кадровой синхронизации в начало пакета добавлена 31-битная последовательность Голда, в результате чего сформировался итоговый кадр длиной 133 бита.

При переходе к временной области каждый бит был представлен десятью отсчетами, после чего сигнал длиной 1330 отсчетов был помещен в общий массив со сдвигом на 666 отсчетов и сложен с белым гауссовским шумом при среднеквадратическом отклонении 0,1. Корреляционный приемник на основе функции взаимной корреляции точно определил начало синхросигнала на 667-м отсчете, что позволило корректно отбросить лишние отсчеты в начале буфера. Последующее накопление по 10 отсчетов на символ и сравнение с порогом, равным половине длительности символа, обеспечили безошибочное восстановление всех 133 бит кадра.

После удаления последовательности Голда повторный расчет CRC дал нулевой остаток, подтвердив отсутствие ошибок при передаче, а ASCII-декодер без искажений восстановил исходный текст «Demin Sergei». Спектральный анализ не подтвердил влияние шума на принимаемый сигна. Сравнение спектров для разной длительности символов наглядно показало обратную зависимость между длительностью импульса и шириной занимаемой полосы: при уменьшении длительности символа вдвое спектр заметно расширяется, а при увеличении вдвое сужается.

Таким образом, поставленные задачи выполнены полностью. Полученная модель подтвердила работоспособность связки из псевдослучайных последовательностей Голда, корреляционного приема и циклического избыточного кода для надежной синхронизации и контроля ошибок в системах мобильной связи.
